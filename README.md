One fortune cookie line for a crypto trader who was just liquidated, entered in
[Fortune Cookie for the Liquidated Trader](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c)
on make.fun.

The program writes a single fortune to `/output/entry.txt`:

> You will meet a tall, dark stranger. He is the liquidator, and he already has your keys.

Run it with Node 22.18 or later:

```sh
node main.ts
```

The program self-checks the gate before writing: 1–160 characters, at most 20
words, a single line.
